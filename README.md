# MK: Epstein vs P. Diddy (Online Edition)

2D-файтинг на HTML5 Canvas с поддержкой P2P онлайн-мультиплеера через WebRTC (PeerJS).

## Режимы игры
- **На одном ПК**: Игрок 1 (WASD + F/G) vs Игрок 2 (Стрелки + K/L).
- **Онлайн 1x1**: Один игрок создает комнату и делится кодом/ссылкой, второй подключается. Физика рассчитывается на хосте, а ввод передается по WebRTC каналу без задержек.

## Управление
- **Ходьба**: A / D (или Стрелки влево / вправо)
- **Прыжок**: W (или Стрелка вверх)
- **Блок**: S (или Стрелка вниз)
- **Удар рукой**: F (или K)
- **Пинок ногой**: G (или L)
